# Базы данных — учебные материалы

Рабочий репозиторий по дисциплине «Базы данных» и онлайн-курсу **«Управление данными» (OpenEdu)**.

Автор: Джанибеков Димаш.

## Что здесь хранится

- `notes/learning-diary-weeks-01-06.md` — авторские заметки: что изучено, какие задачи разобраны, что усвоено.
- `reports/lab-report-template.md` — структура отчета для лабораторных работ недель 9–16.
- `sql/` — появится по мере выполнения лабораторных работ: оригинальные исполняемые SQL-скрипты с комментариями автора.
- Скриншоты результатов тестов будут добавлены после получения с компьютера.

## Статус

Недели 1–5: материалы теории и тестовые задания разобраны; скриншоты результатов еще не приложены.
Неделя 6: изучены предоставленные лекционные материалы; статус тестирования отдельно не подтвержден.
Недели 7–8: ожидают изучения.
Недели 9–16: лабораторные работы и отдельные отчеты впереди.

**Оценки, даты сдачи и результаты выполнения SQL не считаются подтвержденными до добавления соответствующих скриншотов/скриптов.**

## Оформление

Рабочий документ готовится в редактируемом формате ODT, шрифт Times New Roman, 14 пт, межстрочный интервал 1,5, А4. При проверке прикладываются скриншоты из личного кабинета и выполняемые SQL-запросы.

Лекционные PDF предоставлены для самостоятельного изучения. Здесь публикуются **собственные обобщения**, а не копии преподавательских материалов.
